# Mini CRM & ERP Core (PoC)

Легковесный архитектурный прототип (Proof of Concept), демонстрирующий разделение ответственности между доменными областями **CRM** (управление лидами, воронка продаж, прогнозная аналитика) и **ERP** (учет товарной номенклатуры, контроль складских остатков).

Проект реализован без внешних frontend-фреймворков и сложных бандлеров: всё работает на чистом Python (FastAPI + SQLAlchemy) и Vanilla JavaScript (SPA).

---

## Ключевые возможности и бизнес-логика

### 1. CRM-домен (Customer Relationship Management)
* **Управление воронкой продаж:** движение сделок по этапам (`NEW` → `IN_PROGRESS` → `WON` / `LOST`).
* **Бизнес-валидация:** запрет на перевод сделки в статус `LOST` без обязательного указания причины отказа.
* **Метрики и аналитика продаж:**
  * **Фактическая выручка:** сумма только успешно закрытых сделок (`WON`).
  * **Прогнозная выручка (Weighted Pipeline):** расчет вероятностного дохода с учетом весов этапов воронки (NEW = 10%, IN_PROGRESS = 50%, WON = 100%, LOST = 0%).
  * **Конверсия (Win Rate):** расчет отношения успешных сделок ко всем закрытым:
    Win Rate = (WON / (WON + LOST)) * 100%

### 2. ERP-домен (Enterprise Resource Planning)
* **Управление номенклатурой:** учет остатков на складе (`stock_quantity`) и базовой стоимости позиций.
* **Сквозная транзакционность и защита склада:** при попытке перевести сделку в статус `WON` бэкенд проверяет физическое наличие товара.
  * Если товара достаточно: остаток списывается из базы ERP.
  * Если товара не хватает: транзакция прерывается, статус сделки не меняется, а пользователь получает ошибку `400 Bad Request`.

## Технологический стек

* **Backend:** Python 3.10+, FastAPI, Pydantic v2, Uvicorn
* **Database & ORM:** SQLite, SQLAlchemy 2.0
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (асинхронный Fetch API)
* **API Documentation:** OpenAPI / Swagger UI

## Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/](https://github.com/)<ваш-аккаунт>/<название-репозитория>.git
cd <название-репозитория>
```

### 2. Настройка виртуального окружения
* **Windows (PowerShell):**
  ```powershell
  python -m venv .venv
  .venv\Scripts\Activate.ps1
  ```
* **macOS / Linux:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python -m uvicorn main:app --reload
```

После старта приложения:
* **Веб-интерфейс:** откройте [http://127.0.0.1:8000](http://127.0.0.1:8000)
* **Интерактивная документация Swagger UI:** откройте [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

*(Файл базы данных `app.db` создается автоматически при первом запуске и наполняется базовыми тестовыми товарами).*

## API Эндпоинты

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/` | Отдает SPA-интерфейс (`index.html`) |
| `GET` | `/api/products` | Список доступных товаров и остатков на складе (ERP) |
| `GET` | `/api/deals` | Список всех сделок и их текущих стадий (CRM) |
| `POST` | `/api/deals` | Создание новой сделки (расчет суммы по цене из ERP) |
| `PATCH` | `/api/deals/{id}/stage` | Смена стадии сделки (списание остатка при `WON` или валидация причины при `LOST`) |
| `GET` | `/api/analytics` | Расчет суммарных метрик (конверсия, факт/прогноз выручки) |
